1. First: VIP anti-colocation constraints

We have 7 VIPs and want no two VIPs on the same node.

Run this exact loop:

for a in 021 022 023 024 025 026; do
    for b in $(seq $((10#$a + 1)) 027); do
        printf -v b '%03d' "$b"
        pcs constraint colocation add clnvrm${a}-vip with clnvrm${b}-vip -INFINITY
    done
done

This creates the 21 pairwise anti-colocation constraints.

Then check:

pcs constraint config --full | grep 'vip with'

You should have 21 lines.

Now check the critical VIP:

crm_simulate -Ls | grep -A10 -B5 'clnvrm024-vip allocation score'
